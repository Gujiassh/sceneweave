# Free home starter

## Why

Fresh installations need a redistributable furnished home after the external owner asset directory became unavailable. Supply a complete recognizable home and live device targets through the existing generic starter contract.

## Scope

Curated CC0 furniture, separately authored supplementary devices and cutaway architecture; reproducible generator; explicit provenance, metric normalization, budget and semantic target mapping. Existing owner model generator and historical specifications remain references.

## Acceptance

A real rendered preview must show furnished living/dining, bedrooms, kitchen, bath and circulation. The generated archive must import through the existing SceneDocument API and generic bootstrap descriptor, preserve five existing device target meanings and pointers, support editing and Run, and survive a clean clone through tracked source assets plus a reproducible command. Source/license and actual geometry budgets require independent review.
